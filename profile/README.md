# SeePM

**Run paid media from the AI you already use.**

SeePM connects your ad accounts and keeps each client's goals, plan and history, so your AI works on the right account with the full context. Changes follow your team's approval rules, and every one is recorded.

Google, Meta, TikTok, LinkedIn, X, Reddit, Apple and more, plus GA4 and Tag Manager.

### Open source

**[paid-skills](https://github.com/SeePm/paid-skills)**: free skills for media planners. Brief, plan, audit and present paid media from the real business outcome. Works in Claude Code, Codex and any agent that reads skills.

```
/plugin install media-planner --marketplace SeePm/paid-skills
```
